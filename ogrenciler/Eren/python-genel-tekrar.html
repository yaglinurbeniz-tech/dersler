SİSTEM 01

Temeller · koşul & mantık

OFFLINE

Ne yazdırır?

x = 7
y = 3
if x > y and x % 2 == 1:
    print("evet")
else:
    print("hayır")
and iki koşulun da doğru olmasını ister. İki koşulu ayrı ayrı düşün.
7 > 3 doğru mu? 7 % 2 == 1 yani 7 tek mi? İkisi de doğruysa hangi dal çalışır?
İkisi de doğru → if dalı çalışır. Çıktı tek kelime, küçük harf.

toplam = 0
for i in range(1, 5):
    toplam += i
print(toplam)
range(1, 5) hangi sayıları verir? Son sayı (5) dahil değil.
1, 2, 3, 4 sayılarını toplam'a ekliyor. Başlangıç 0.
0 + 1 + 2 + 3 + 4 = ?
SİSTEM 03

Veri yapıları · sözlük

OFFLINE

puanlar = {"eren": 90, "ada": 75}
print(puanlar["eren"] - puanlar["ada"])

eren'in puanı 90, ada'nınki 75. Aralarında çıkarma yapılıyor.
90 - 75 = ?
SİSTEM 04

Fonksiyonlar · return

OFFLINE

Ne yazdırır?

def kare(n):
    return n * n

print(kare(3) + kare(4))
kare(n) fonksiyonu n*n döndürür. kare(3) kaç eder?
kare(3) = 9, kare(4) = 16. İkisi toplanıyor.
9 + 16 = ?
SİSTEM 05

String metodları

OFFLINE

Ne yazdırır? (Not: baştaki/sondaki boşluklara dikkat)

s = "  SpeakGuard  "
print(s.strip().lower())
.strip() baştaki/sondaki boşlukları kırpar, .lower() küçültür. Sırayla uygulanıyor.
" SpeakGuard " → önce boşluklar gider, sonra tüm harfler küçülür.
Sonuç tek kelime, hepsi küçük harf, kenarlarında boşluk yok.
SİSTEM 06

Hata yönetimi · try/except

OFFLINE

Ne yazdırır?

try:
    sayi = int("abc")
    print("sayı hazır")
except ValueError:
    print("hata var")
int("abc") çalışır mı? "abc" sayıya çevrilebilir mi?
Çevrilemez → ValueError fırlar → try yarıda kesilir, except devreye girer. "sayı hazır" hiç yazılmaz.
Sadece except içindeki print çalışır. İki kelime, küçük harf.
