Görev 1 — Araba
1Isınma

İki araba, iki ayrı depo

Aşağıdaki kodu kendi editöründe yaz ve henüz çalıştırma.

class Araba:
    def __init__(self):
        self.yakit = 100

    def sur(self):
        self.yakit -= 30

araba1 = Araba()
araba1.sur()
araba1.sur()
araba2 = Araba()

print(araba1.yakit, araba2.yakit)
Görev 2 — Üç Öğrenci
2Orta

Üç nesne birden

Bu sefer üç nesne var. Kodu yaz, henüz çalıştırma, önce tahmin et.

class Ogrenci:
    def __init__(self):
        self.puan = 0

    def puan_ekle(self):
        self.puan += 10

ogrenci1 = Ogrenci()
ogrenci1.puan_ekle()
ogrenci1.puan_ekle()
ogrenci1.puan_ekle()

ogrenci2 = Ogrenci()
ogrenci2.puan_ekle()

ogrenci3 = Ogrenci()

print(ogrenci1.puan, ogrenci2.puan, ogrenci3.puan)
Görev 3 — Sıra Önemli mi?
3Kritik

Aranın arasına yeni nesne girerse

Bu görevde bitki1 iki kez sulanıyor, SONRA bitki2 doğuyor, SONRA bitki1 bir kez daha sulanıyor. Dikkatli oku, sıraya çok dikkat et.

class Bitki:
    def __init__(self):
        self.boy = 10

    def sula(self):
        self.boy += 5

bitki1 = Bitki()
bitki1.sula()
bitki1.sula()

bitki2 = Bitki()

bitki1.sula()

print(bitki1.boy, bitki2.boy)

4Transfer

Telefon (senin bulduğun örnek!)

Geçen ödevde kendi bulduğun telefon örneğini hatırlıyor musun? Şimdi onu gerçek kod olarak yaz. Aşağıdaki tarife göre kendi sınıfını sıfırdan yaz — bu sefer kod verilmiyor:

Yaz: Telefon sınıfı, __init__(self, marka) ile self.marka ve self.sarj = 50 ayarlansın. sarj_et(self) metodu şarjı 20 artırsın.

Sonra: iphone = Telefon("iPhone"), iki kez sarj_et() çağır. Sonra galaxy = Telefon("Galaxy") oluştur (henüz şarj etme). En sonda print(iphone.sarj, galaxy.sarj) yaz.
